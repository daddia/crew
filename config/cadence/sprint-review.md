# Sprint review ritual

**Status:** Authored, not scheduled (enable after weekly planning spike passes).

**Agents:** `delivery-lead` + `product-manager`  
**Schedule (future):** End of sprint, Friday 15:00 AEST

## Purpose

Close the sprint loop: demo notes, validation status, retrospective draft.

## Workflow

1. Read `website/docs/work/sprint-{n}/plan.md` and linked issues.
2. Mark completed tasks; leave incomplete items with reason.
3. Invoke `sprint` skill in **retrospective** mode → `website/docs/work/sprint-{n}/retrospective.md`.
4. Open PR with retrospective; tag friction items for `digital-agency` catalogue if persona/skill gaps.

## Acceptance

- [ ] Retrospective PR opened (not auto-merged)
- [ ] Issue states updated to match merged PRs
- [ ] Carry-over tasks identified for next planning ritual
