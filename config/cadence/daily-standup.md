# Daily standup digest

**Status:** Authored, not scheduled (enable after weekly planning spike passes).

**Agents:** `delivery-lead`  
**Schedule (future):** Weekdays 08:30 AEST

## Purpose

Produce a concise standup digest from GitHub Issues and open PRs across linked repos —
not a meeting replacement.

## Workflow

1. Query org project **Carinya Parc Delivery** for In progress / In review items.
2. Summarise per squad: done since yesterday, in flight, blocked.
3. Post digest as a comment on the active sprint plan PR or `carinyaparc/docs/delivery/standup-{date}.md` PR.

## Output rules

- Cite issue numbers and PR links — no vague status
- Blockers get a recommended owner agent slug
- Do not change backlog priority without human approval
