# Principles guide the development of agentic-first process

1. **Artefacts are the source of truth**: if it isn't in the artefact, it isn't agreed → _What we trust_
2. **Humans own gates**: every approval, kill/advance decision, and merge is a named human → _Who decides_
3. **Agents own first drafts**: no human should be writing from a blank page → _How we work_
4. **Validate before build**: evidence kills bad ideas cheap; sprints kill them expensive → _When we build_
5. **Small slices, fast signals**: the smallest thing that proves the outcome, then iterate → _How we ship_
